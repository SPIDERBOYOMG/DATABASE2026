Repository for laboratory work in the Database Systems course.

📚 About

This repository contains laboratory assignments completed as part of the Database Systems course. The labs cover the fundamentals of relational databases, database design, SQL, data manipulation, and database management.

🧪 Laboratory Works

Each laboratory work is stored in a separate directory and may contain SQL scripts, documentation, datasets, and other required files.

This repository is intended for educational purposes and is used to organize and store laboratory assignments for the Database Systems course in 2026.
